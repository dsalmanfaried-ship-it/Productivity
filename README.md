# 🌲 غابتي – تطبيق تركيز وإنتاجية (زي Forest) بالعربي

تطبيق ويب في صفحة واحدة، من غير سيرفر ولا حساب:

- مؤقت تركيز (مؤقت / ستوب ووتش) والشجرة بتكبر، وبتموت لو سبت التاب أكتر من المهلة.
- غابة وإحصائيات وتاجات وعملات ومتجر أشجار (نيّات).
- مواقيت الصلاة بحساب فلكي بدون نت، وبريك للصلاة (فجر، ضحى، ظهر، عصر، مغرب، عشاء، وتر) وتنبيهات وفضل التبكير.
- بونص ×2 من الفجر للظهر، ومدة تركيز تلقائية قبل الصلاة بـ ٥ دقايق.
- بريك مذاكرة ٥/١٠/١٥/٢٠ دقيقة، مع سورة يس اختيارية بشيخ عشوائي وتكملة من آخر مكان.
- تلاوات سورة البقرة (إسلام عثمان وأحمد كاسب) كخلفية للتركيز.
- يشتغل بدون إنترنت، ومتثبّت كتطبيق (PWA).

## الملفات

```
index.html            التطبيق كله
sw.js                 service worker (هيكل التطبيق بدون نت)
manifest.json         بيانات التثبيت كتطبيق
icon.svg / icon-*.png الأيقونات
audio/                ملفات التلاوات (بقرة + يس)
```

## الرفع على GitHub ونشره (GitHub Pages)

1. أنشئ مستودع جديد على GitHub (مثلًا `ghabaty`).
2. فك ضغط الأجزاء التلاتة في **نفس المجلد** (`ghabaty`)، وهتلاقي فيه كل الملفات ومجلد `audio`.
3. من صفحة المستودع: **Add file ← Upload files**، واسحب محتوى المجلد (index.html وباقي الملفات ومجلد audio). لو رفعت على دفعات، كل دفعة لحد ١٠٠ ملف.
4. أو بالأوامر:
   ```
   cd ghabaty
   git init && git add . && git commit -m "غابتي"
   git branch -M main
   git remote add origin https://github.com/<اسم-حسابك>/ghabaty.git
   git push -u origin main
   ```
5. من **Settings ← Pages** اختار **Deploy from a branch**، الفرع `main` والمجلد `/ (root)`.
6. بعد دقيقة أو اتنين الموقع هيشتغل على: `https://<اسم-حسابك>.github.io/ghabaty/`

## العمل بدون إنترنت

- افتح الموقع مرة واحدة بنت: التطبيق بيتخزن تلقائيًا (service worker).
- لتنزيل التلاوات: **الإحصائيات ← الإعدادات ← تنزيل التلاوات للاستخدام بدون نت** (حوالي ١٢٦ ميجا)، أو من زرار الصوت.
- المؤقت والغابة والإحصائيات ومواقيت الصلاة شغالين بدون نت من غير أي تنزيل.
- ممكن تثبّته كتطبيق: من المتصفح اختار **Install / إضافة إلى الشاشة الرئيسية**.

## ملاحظات

- بياناتك (الجلسات والعملات والإعدادات) بتتخزن في متصفحك فقط (localStorage / IndexedDB).
- مواقيت الصلاة حسابها تقريبي وقد يختلف دقيقة أو اتنين عن التقويم الرسمي. راجعها مع مسجد منطقتك.
- نصوص الأحاديث مصاغة بالمعنى. راجع الأصل أو اسأل أهل العلم.
- التسجيلات الصوتية حقوقها لأصحابها (القرّاء / الناشرين). المستودع العام معناه إعادة نشرها للعامة، فتأكد إن المصدر بيسمح بكده قبل ما تجعله عام.
