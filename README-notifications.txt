غابتي — إصلاح وربط إشعارات الويب

ما تم تعديله:
- إضافة زر «تفعيل إشعارات المذاكرة» داخل نافذة «حسابي» للمستخدم المسجل دخوله.
- إضافة notifications.js لطلب إذن الإشعارات، وتسجيل عامل خدمة مستقل تحت /fcm/، واستخراج FCM token وحفظه في users/{uid}/fcmTokens.
- إضافة fcm/firebase-messaging-sw.js لاستقبال إشعارات FCM أثناء وجود التطبيق في الخلفية.
- لم يتم استبدال sw.js الخاص بالتطبيق؛ ملفه الأصلي غير موجود ضمن الملفات التي وصلتني، واستبداله دون الاطلاع عليه قد يعطل التخزين دون إنترنت.

قبل الرفع — خطوة لازمة:
1) افتح Firebase Console > Project settings > Cloud Messaging > Web Push certificates.
2) أنشئ/انسخ مفتاح Web Push public key.
3) افتح notifications.js واستبدل القيمة PASTE_FIREBASE_WEB_PUSH_CERTIFICATE_KEY_HERE في FCM_VAPID_KEY بالمفتاح العام الفعلي.
4) ارفع index.html وnotifications.js إلى جذر الموقع، وارفع مجلد fcm كما هو بحيث يصبح المسار /fcm/firebase-messaging-sw.js.
5) احتفظ بملف sw.js الأصلي الموجود على استضافتك كما هو. ملف التطبيق الأصلي غير مرفق هنا، لذلك لم أستطع دمج كود FCM داخله أو التحقق من عمله.
6) تأكد من نشر firestore-rules.txt. القواعد المرفقة تسمح للمستخدم بقراءة/كتابة رموز أجهزته داخل fcmTokens.
7) افتح الموقع من Chrome عبر HTTPS، سجّل الدخول، ثم حسابي > تفعيل إشعارات المذاكرة، واسمح بالإشعارات.

الاختبار الذي أُجري هنا:
- فحص نحوي JavaScript لسكريبت index.html المضمن وnotifications.js وملف عامل الخدمة: اجتازوا الفحص.
- تحقق ساكن من وجود زر التفعيل وربط ملف notifications.js: ناجح.
- لم يمكن اختبار صلاحية Firebase الفعلية أو الإرسال والاستقبال على الاستضافة من هذه البيئة.

حدود مهمة:
- مفتاح Web Push العام مطلوب من مشروع Firebase ولا يمكن تخمينه؛ من دونه سيعرض الزر رسالة تطلب إضافته.
- حفظ FCM token لا يرسل إشعارًا بحد ذاته. إرسال تذكير الساعة 6 مساءً يحتاج Cloud Functions أو خادمًا موثوقًا مجدولًا، مع استخدام Firebase Admin على الخادم فقط. لا تضع Service Account أو مفاتيح Admin في ملفات الموقع.
- أرسل لقطة شاشة بعد الضغط على زر التفعيل (أو نص رسالة الخطأ) بعد النشر لاستكمال اختبار وصول أول إشعار.
