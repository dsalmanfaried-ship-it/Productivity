ملفات جاهزة لموقع Productivity / غابتي

1) ارفع index.html مكان الملف الحالي (تمت إضافة سطر تحميل واحد فقط قبل </body>).
2) ارفع notifications.js بجوار index.html.
3) ارفع sw.js مكان الملف الحالي. تم الحفاظ على كود التخزين دون إنترنت وإضافة استقبال FCM.
4) انسخ firestore-rules.txt إلى Firestore Rules ثم انشر القواعد.

ملاحظات:
- إعداد Firebase Auth الموجود لم يتغير.
- بيانات الغابة ومزامنتها لم تتغير.
- زر تفعيل الإشعارات يظهر في نافذة الحساب بعد تسجيل الدخول.
- الإشعارات المجدولة (مثل تقييم الساعة 6 مساءً) لم تُفعّل بعد؛ تحتاج Cloud Functions/خادم موثوق لإرسالها.
- لا تضع Service Account أو مفاتيح Admin في ملفات الموقع.
- بعد الرفع افتح الموقع في Chrome عبر HTTPS، سجّل الدخول، وافتح نافذة حسابي واضغط تفعيل إشعارات المذاكرة.
